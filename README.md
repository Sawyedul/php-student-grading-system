# PHP Student Grading System

A PHP-based student grading system developed as part of a University of the People programming assignment.

## Features

- Calculates total marks, average scores, and percentages.
- Determines pass or fail results.
- Checks Honor Roll eligibility.
- Counts failed subjects.
- Identifies students placed on academic probation.
- Processes five students using loops.

## Technologies Used

- PHP 8.6
- Visual Studio Code
- GitHub

## How to Run

1. Install PHP on your computer.
2. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

3. Open the project folder in your terminal.
4. Run:

   ```bash
   php student_grading_system.php
   ```

5. Enter the examination and subject scores when prompted.
